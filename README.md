# 🌐 Weblix

**Weblix** is a modern web development agency website built using HTML and CSS. It showcases a clean, responsive, and professional landing page designed to highlight web development services and create a strong first impression.

## 🚀 Features

* Responsive Navigation Bar
* Modern Hero Section
* Full-screen Background Image
* Dark Overlay for Better Readability
* Call-to-Action Button
* Mobile-Friendly Design
* Clean and Organized Code
* Easy to Customize

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Optional)
* Flexbox
* Responsive Design

Weblix/

## 🎯 Purpose

The goal of this project is to provide a modern, responsive, and visually appealing landing page for a web development agency. It can be used as a starting point for agency websites, portfolios, startups, or freelance businesses.

## 💻 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/mohdrehxn/weblix.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.

No additional setup or installation is required.
